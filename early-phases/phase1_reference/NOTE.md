# Phase 1 Reference Copy

This directory preserves the phase-1 UART implementation (TX/RX/loopback,
no parity or error handling) exactly as it stood before this phase's
work began, for reference and comparison. It is not part of the buildable
phase-2 project -- see the top-level `README.md` and `docs/architecture.md`
Section 1 ("What changed from phase 1, and why") for the review of this
code that motivated phase 2's design decisions.

These files are not compiled by the Makefile and are not needed to build
or simulate the current design.
